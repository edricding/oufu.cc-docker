# OUFU 静态网页

直接双击 index.html 即可打开，无需 Node.js、localhost 或网络连接。

保留内容：
- index.html：OUFU / LOGIN 双入口和登录表单。
- entrance.css：响应式布局和动画。
- entrance.js：悬浮反馈、展开转场、页面切换及密码显示。
- home.html：保留用户清空后的官网页，后续可在 body 内添加内容。
- assets/figtree-latin-wght-normal-D_ZTVpCC.woff2：页面使用的本地字体。

所有资源使用相对路径，移动或分享时请保留整个目录结构。
登录表单为前端演示，不发送或保存用户名和密码。
